# Gestión: ritmo semanal

Estado: vigente. Aplicado por Erik. Fuente de verdad del **estado**: Monday
`18432808588`.

## lunes, 15 min

1. `bun run doctor` en local para quien toque código.
2. Revisar `🎯 SPRINT ACTUAL`: ¿lo que está `En progreso` sigue en progreso?
3. Mover a `🚧 DESARROLLO` lo que ya tiene responsable empezando.
4. Revisar fechas de `Cronograma`. Una fecha vencida se re-planifica aquí o se
   dice por qué no.

## miércoles, 10 min

- Bloqueos. Un bloqueo de más de 24 h se escala el mismo día.
- La columna `Depende de` refleja la realidad. Si algo espera a otra cosa, se
  escribe la dependencia.

## viernes, 20 min

1. `bun run verify` en verde en la rama de cada persona.
2. Marcar `Listo` lo que tenga evidencia en la columna `Enlace`.
3. Mover a `🏁 COMPLETADO` lo que esté `Listo` y revisado.
4. Actualizar `gestion/TRAZABILIDAD.md` si cambió el mapeo.

## Fin de sprint

- Se cierra la columna `Cronograma` de las tarjetas del sprint.
- Se revisan las tarjetas que quedaron `Por hacer`: re-planifican o se cancelan
  con confirmación. Nunca se archivan en silencio (`docs/REGLAS.md`).
- Se escribe el resumen en `docs/diario/` cuando haya una decisión que otro
  entender en tres meses.
